# Security Notes

## Minimum Security Standards

- Private repository only
- No secrets committed to code
- Environment variables stored outside GitHub source files
- Role-based access control required
- Audit logging required
- Microsoft 365 SSO preferred
- MFA preferred
- HTTPS required in production
- Daily backups required for production database

## Prohibited

- Passwords in code
- API keys in code
- Database credentials in code
- Private certificates in code
- Shared user accounts
