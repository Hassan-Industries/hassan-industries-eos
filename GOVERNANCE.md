# Governance

This repository is maintained as a private enterprise software project of Hassan Industries.

## Authority

Hassan Capital Partners, LLC provides governing authority.

Hassan Corporate Agents administers the system.

## Branching Standard

- `main` = production-ready
- `dev` = development
- `feature/*` = feature work

## Change Control

All major changes should be documented in `CHANGELOG.md`.

No secrets, credentials, private keys, or production data shall be committed to this repository.
